# PhaseNet Picker Source

Independent AI-PAL PhaseNet picker package containing preprocessing and sample
construction, model and dataset definitions, training, continuous inference,
and positive-window inference. It can run alone or as one member of an AI-PAL
ensemble. This package is separate from the reference SeisBench PhaseNet
branch. Executable workflows and editable configs live in `../2_train_picker/`
and `../3_run_ai_pal/`.
