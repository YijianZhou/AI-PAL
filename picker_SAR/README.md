# SAR Picker Source

SAR model structure, datasets, training loops, continuous inference, positive-event
inference. Use `train.py`/`dataset.py` for the
standard continuous-data model and `train_pos.py`/`dataset_pos.py`/`picker_pos.py`
for positive-event experiments. Executable workflows live in `../2_train_picker/`
and `../3_run_ai_pal/`.
